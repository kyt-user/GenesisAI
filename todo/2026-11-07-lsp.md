# J10/J11：异步语言服务、完整分页与授权多根

实现替换旧的一次性同步 query；没有旧协议/接口兼容分支。由主代理整合总台账、用户指南与最终审计。

## 当前接口

- `lsp_query(operation, path, line?, column?)`：立即提交，返回 `query_id` 与 `queued`，外部服务启动仍走既有明确授权。operation 为 definition/references/diagnostics/capabilities；定义、引用使用从1起始的UTF-16行列。
- `read_lsp_result(query_id, offset?, limit?)`：读取 queued/running/completed/failed/cancelled/unknown；完成后按 next_offset 分页，默认100、单页最多1000位置，**没有100条总量截断**。该工具只读现有查询，不启动进程，不再次要求服务启动审批。
- `cancel_lsp_query(query_id)`：提交取消；取消也可由所属用户运行取消、关闭服务或权限降级触发。查询期间文件改变不阻止取消。
- `capabilities` 返回已实现、当前服务器支持、明确未实现的能力。diagnostics 只接入服务器声明的拉取诊断；rename/codeAction/formatting/push_diagnostics 明确未实现，不伪装支持。

`lsp.json` 示例：

```json
{
  "max_concurrent": 4,
  "servers": {
    ".py": {
      "command": ["python", "-m", "pylsp"],
      "language": "python",
      "workspace_roots": [".", "../dependency"],
      "startup_timeout_seconds": 120,
      "query_timeout_seconds": 120
    }
  }
}
```

工作根必须同时属于当前文件授权；使用多个根时要求服务声明 workspaceFolders 支持。缺省根为当前工作区。启动与查询分别计时、可配置，不把两者共用45秒；前台只负责提交/观察。背景宿主线程默认4并发、可配置；同一连接按协议串行，独立服务可并行。

LSP 查询同时遵守 `state_root/jobs/limits.json` 的全局 `max_concurrent`（默认4），与命令、MCP、外部工具、维护任务共用 `jobs/slots/{index}.lock` 跨进程执行槽位。先等待同一连接的锁，再申请全局槽位，避免等待连接时挤占总配额；等待期间状态保持 queued、更新心跳、可取消，不占前台工具执行线程，也不消耗启动或查询时限。取得槽位后再次校验当前授权、源文件与根范围，然后运行；成功、失败、取消均释放槽位，持久空闲连接不占执行槽位。LSP 自身 `max_concurrent` 仍约束本服务并发，不能绕过全局配额。

`register_lsp(project_dir, registry, loader, *, state_root)` 与 `LanguageService(..., *, state_root, max_concurrent=4)` 要求显式传入状态根，不从项目路径猜测。ToolRuntime 调用同步更新，不保留旧构造签名。尚未获得本地执行线程的排队查询也由心跳线程取消，不必等前面的长查询结束。

连接保留在宿主，文件后续变化通过 didClose/didOpen 更新完整文本。服务关闭会取消排队/运行请求、终止所有所属进程，之后可再次查询启动。异步任务清掉一次性工具截止时间，使用自己的启动/查询截止时间；父运行取消仍传播。写管道和读消息均可中断，不让阻塞I/O卡住宿主主调用链。

结果与心跳保存在项目状态的 `lsp-results/`，以随机 query_id 命名，不改源文件。分页绑定工作区、服务配置、声明根和源文件哈希；每页重新验证实际授权与目标文件哈希，改变后明确拒绝旧结果。完整快照在会话/服务重开后仍能读；活动宿主心跳失联标 unknown，不自动重发。临时 Windows 文件分享锁复用 jobs.storage 的原子保存/读取重试；无法保存最终状态时明确 unknown。此复用不修改 jobs 模块。

保留8MiB协议消息预算、32行/每行2048字节响应头边界；原文超出消息预算时在读取全文前拒绝。非本地 file URI、缺失或未授权位置按原因统计 omitted；不会将越界位置混进分页结果。分页总数是全部获准位置数。

协议参考：[微软 LSP 3.17 元模型](https://github.com/microsoft/language-server-protocol/blob/gh-pages/_specifications/lsp/3.17/metaModel/metaModel.json)，用于核对工作根请求、诊断与位置编码字段。
