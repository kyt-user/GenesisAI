# BUG-002：历史文件变化阻断会话

[返回目录](目录.md)

日期：2026-11-03。状态：已修复并通过回归。

## 现象与复现

1. Agent 读取项目文件，系统登记文件来源及 SHA-256。
2. Agent 合法修改文件，或应用更新 `agent_docs/index.json`。
3. 用户继续提问，新一轮在调用模型之前报错：“历史资料已变更，请新建会话重新读取”。

本次日志第 1970 行记录异常来自 `Runner.start()` → `Store.verify_sources()`。最先失效的来源是应用自身更新的 `agent_docs/index.json`，另一个是修复前的 `task_board.py`。修复后重新读取源码生成了新来源，但旧来源仍在，因而依然会触发旧校验。

## 根因

原设计把全部历史文件来源视为不可变输入。每次开始或恢复会话都要求所有历史哈希与当前文件完全一致，未区分“历史快照仍有保留价值”和“历史内容已经不能代表当前文件”。产物创建后再合法编辑，也存在使用旧哈希验证的问题。

```text
原校验():
    for source in 全部历史文件来源:
        if 文件不存在 or 当前哈希 != 历史哈希:
            raise "历史资料已变更，请新建会话重新读取"
    # 一个旧快照就足以阻断整个会话
```

## 修复方法与伪代码

保留原来源、产物记录及历史哈希，新增失效标记；文件变化不再使会话直接失败。开始、恢复会话和构建模型上下文时更新本地快照状态。模型需要当前内容时重新读取；旧引用不可证明当前内容。

```text
refresh_local_files():
    changes = []
    for snapshot in 历史本地来源 + 产物快照:
        path = 解析真实路径(snapshot.path)
        if path 不在当前授权读取范围或输出目录:
            raise 授权范围错误
        current_hash = 文件存在 ? SHA256(path) : None
        stale = current_hash != snapshot.sha256
        if stale 与已保存状态不同:
            snapshot.stale = stale
            changes.append(引用, 路径, stale)
        # 不改写 snapshot.sha256，不删除历史记录
    if changes 非空:
        保存会话
        记录 local_files_changed 事件

构建模型上下文():
    refresh_local_files()
    将失效引用和路径加入可信运行时提示
    告知模型：历史内容不代表当前文件，需要时重新 read_files

验证回答引用(ref):
    return ref 已登记 且 ref 未失效 且满足原有来源规则
```

产物校验保留实际完整性检查，但按已记录的最新修改验证：

```text
verify_artifacts(current_run_only):
    for 每个产物路径的最新记录:
        change = 该路径最新的合法变更记录
        if 只检查当前运行 且该产物本轮未创建或修改:
            continue
        if 路径越过输出目录:
            raise 越界错误
        if 最新记录是合法删除或移动:
            continue  # 原路径不再是当前交付产物，历史仍保留
        expected = 最新变更的 after_sha256 或创建时哈希
        if 文件不存在 or SHA256(path) != expected:
            raise 产物完整性错误
```

源码位置：

- [persistence/session.py](../../src/genesisai/core/persistence/session.py)：当前的 `refresh_local_files()`、`verify_sources()`、`verify_artifacts()`；历史入口为 `core/state/store.py`。
- [prompt/context_budgeter.py](../../src/genesisai/core/prompt/context_budgeter.py)：失效快照提示。
- [agent/recovery.py](../../src/genesisai/agent/recovery.py)：失效来源引用校验。
- [agent/loop.py](../../src/genesisai/agent/loop.py)：新一轮、恢复及最终产物验证入口。

## 验证与边界

- 修改或删除文件后，重新加载会话仍能刷新来源；原哈希和引用保留，旧引用标为失效。
- 重新读取当前内容产生可用的新来源；旧来源仍保留。
- 创建后合法编辑产物能够通过验证；未记录的外部篡改仍被产物校验拒绝。
- 修复和测试完成后，可继续同一会话追问。
- 原故障会话在临时副本上验证通过，识别出两条失效来源；没有修改原历史数据。

本修复没有关闭授权边界、网络来源缓存完整性检查或当前交付产物的完整性检查。它也不会自动重写旧运行的错误结论，不是历史迁移或删除流程。
