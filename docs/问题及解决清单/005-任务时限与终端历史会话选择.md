# BUG-005 任务时限被档位覆盖与历史会话入口

2026-11-03 实现。对应会话 `session_58760d5c9c69447b`。

## 复现与原因

16:55:33 用户询问之前聊过什么。首次模型请求返回 HTTP 503，重试在约 105.5 秒后返回工具调用。启动配置为 300 秒，普通问答档位内部配置为 60 秒，运行器取两者较小值，返回“模型返回时已超过运行截止时间”。

该次启动创建了新会话，之前的对话需要通过 `--session` 显式加载。新增终端选择入口以便继续已有任务。

## 时间参数（2026-11-06 当前实现）

- `--seconds` 控制一次 Run 的累计执行时长，默认不限；恢复同一 Run 不重置消耗。档位切换不缩短用户预算。
- 请求采用 `request_timeouts`：连接 `connect=30`、首个有效输出 `first_token=300`、有效输出间隔 `idle=300`、请求总时长 `total=null`，单位为秒。默认值见 `shared/request_timeouts.py`。
- CLI 使用 `--request-connect-timeout`、`--request-first-token-timeout`、`--request-idle-timeout`、`--request-total-timeout` 逐项覆盖模型配置。总时限允许 `none`，其余必须为有限正数。
- 每次请求及重试重新计算剩余任务和恢复预算；摘要调用也受剩余任务时长约束。
- 用户等待批准的时长从任务消耗中排除。工具执行前检查截止时间，命令进程的时限取显式工具配置和剩余任务时间的较小值。
- 总结请求超时时，只有当前修改已验证、计划与能力验收条件满足且无待收取作业，才生成有证据的运行记录摘要；否则保存未完成进度。

正文、推理和工具参数片段刷新空闲计时，心跳和空角色片段不会。非流式调用以完整响应作为首个有效输出。统一异步传输在响应头或流读取等待期间也可被取消；请求到期会中断等待并关闭连接。连接失败、传输断流及分层超时由宿主供应商恢复预算处理，SDK 不叠加隐藏重试。日志记录具体超时阶段；半截工具调用不执行。

## 终端会话选择

输入 `/` 并回车，选择 `/sessions`，或直接输入 `/sessions`。

列表按最近更新时间排序，展示最近用户问题摘要、时间、会话 ID、工作区及状态。交互终端支持方向键、输入搜索、回车确认和 Esc 取消。管道输入使用序号选择，空输入取消。

```python
selected = choose(read_valid_session_files(), exclude=current_session)
if selected is None:
    return_to_current_session()

restore_saved_workspace_and_permissions(selected)
load_workspace_environment_using_process_env_priority()
rebuild_model_and_runtime()
switch_active_session_and_logger()
show_workspace_and_session_status()
```

恢复会话时使用其原工作区、授权目录、权限和历史检查点。切换工作区重新加载 ENV 和当前用户模型配置。不存在的工作区、无效授权路径与不可读取的历史文件会显示错误。取消选择保留当前会话。当前任务尚在运行或等待确认时，先处理当前任务再切换。

`--session ID` 保留为启动入口。`/resume` 用于当前会话内中断运行的恢复。加载已完成或已达到时限的会话后，可以输入新消息继续执行。

## 验证

[test_time_limits_sessions.py](../../tests/test_time_limits_sessions.py) 覆盖普通问答使用显式时限、切换档位不改截止时间、重试使用剩余时间、超时后不重试、已验证工作的摘要回退、通过 `/` 菜单恢复另一工作区、取消选择和损坏文件跳过。

本次使用受控模型和临时目录进行离线验证。真实 API 的 thinking 历史字段问题继续记录在 BUG-004。

历史阶段专项验证为 9 项通过，包含 8 项新增回归及更新后的截止时间回归。此前两组相关回归分别为 40 项与 36 项通过。全量检查得到 416 passed、6 failed、1 skipped，其中一项旧测试使用负数时限，已更新并单独复测通过。其余为 4 项已有测试资料缺失及当前沙箱拒绝创建 Windows 目录联接。完整结果保存在本机 `temp/time-session-full.txt`。
