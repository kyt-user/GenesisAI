# GenesisAI CLI 用户指南

## 1. 产品定位

GenesisAI 在默认或指定工作区中运行一个持续的单 Agent Session。它可以读取和修改代码、执行测试、查看 Git 状态与差异、整理文件、检索公开网络、维护项目工作记忆、加载 Skills，并创建基础办公文档。

它使用 OpenAI 兼容模型协议。默认模型配置随包安装，也可通过终端配置或 `--config <文件路径>` 选择模型。密钥优先取环境变量和 `.env`，没有时使用终端保存的配置。内置 SQLite，无需部署数据库服务。

## 2. 安装与启动

```powershell
cd D:\path\to\your-project
python -m venv .venv
.venv\Scripts\python.exe -m pip install "D:\path\to\GenesisAI[office]"
.venv\Scripts\genesis.exe --workspace .
```

开发仓库内可直接运行：

```powershell
.venv\Scripts\python.exe cli.py
```

Linux 使用对应的 `.venv/bin/python` 和 `.venv/bin/genesis`。V1 的主要实际验收平台是 Windows。

### 阿里云 Token Plan

在工作区或项目根目录的 `.env` 中填写套餐专属密钥。

```dotenv
QWEN_TOKEN_PLAN=sk-sp-替换为你的套餐密钥
```

重启后运行 `genesis --auth`，或在会话中输入 `/auth`，选择「阿里云 Token Plan」。默认选择 `qwen3.8-flash`，菜单提供 `qwen3.8-max`、`auto` 和自定义模型 ID。`/model` 可在当前提供商内切换模型。已有 ENV 密钥时跳过终端密钥输入，ENV 为空时使用终端保存或输入的密钥。

通过 `--config` 使用 YAML 时，填写 `provider: qwen_token_plan` 与对应 `model`。该提供商默认访问 `https://token-plan.maas.qianwenaiapi.com/compatible-mode/v1`，支持用 `QWEN_TOKEN_PLAN_BASE_URL` 覆盖未显式指定的地址。终端配置保存的地址优先于地址环境变量。

套餐适用于交互式编程和智能体工具，具体模型及使用范围见[官方接入文档](https://platform.qianwenai.com/docs/token-plan/personal/token-plan-personal-quickstart)。

## 3. 工作区与状态

未传 `--workspace` 时，新会话使用 `~/.genesisai/workspace`，首次启动自动创建。设置 `GENESISAI_HOME` 后，新会话使用该目录下的 `workspace`。也可用 `--workspace "E:\my-project"` 指定其他目录。相对任务文件路径以当前工作区解释，默认输出到该目录。以下是默认布局。

```text
~/.genesisai/workspace/
~/.genesisai/state/genesis.sqlite3
~/.genesisai/assets/images/
~/.genesisai/projects/<project_id>/
~/.genesisai/logs/
~/.genesisai/traces/
~/.genesisai/command_logs/
~/.genesisai/backups/
```

历史目录不可写时报告错误，不回退到应用或任务目录。`--session SESSION_ID` 从统一目录恢复当前格式的会话及原工作目录；同时指定的 `--workspace` 必须与原目录一致。不提供旧会话格式迁移。项目 Skills、Workflows、MCP 配置保存在应用目录的 `projects/<project_id>/` 下，项目中只读取可选 `AGENTS.md`。`.env` 不允许作为普通资料读取。

## 4. 权限

新会话默认使用用户审批。用 `/permissions` 查看当前模式。

| 模式 | 本地只读 | 写入、运行命令、联网、MCP | 内置文件工具的路径 |
| --- | --- | --- | --- |
| `/permissions user` | 直接执行 | 每次工具调用单独审批 | 已授权路径 |
| `/permissions auto` | 直接执行 | 自动执行 | 允许工作区外的宿主文件 |

用 `/approve` 批准当前展示的调用，或用 `/reject` 拒绝。已有待确认调用在切换模式后仍需处理。授权绑定工具参数和预览，过期后会重新展示。模型对话、会话日志和已启用的项目工作记录随任务运行。MCP 服务按需启动，向声明为只读的服务发送参数也需要对外调用权限。

用 `--permissions user` 或 `--permissions auto` 指定启动模式。恢复会话时沿用保存的模式，未设置时采用用户审批，`/new` 默认用户审批。自动审批下命令以当前系统账号执行，内置文件工具支持宿主绝对路径，仍会检查工具参数和目标冲突，并保护 .env 密钥文件及当前应用状态目录。审批针对一次工具调用。一次已批准的命令可能包含多个动作，并使用当前系统账号的权限。

## 5. Tool 与 Skill

`/tools` 展示启用和禁用两组工具；每轮只向模型提供匹配当前任务及已加载 Skill 的工具。模型可调用 `discover_tools` 按名称、分类或能力查询，每次最多补充 4 个定义，本次任务保留最近发现的 8 个。历史查阅使用只读工具，最终回答和恢复阶段关闭工具。Skill 来自内置、用户级和项目级三层，优先级为项目 > 用户 > 内置。

工具有共同的执行时限和输出预算。审批等待单独计时，批准后重新校验预览。只读工具超时会报告 `tool_timeout`。写入或对外产生副作用的工具一旦开始执行，超时后标记 `unknown_execution` 并中断任务，请先核对结果。模型收到的文本超过工具预算时，会看到预览和 `ref`，可用 `memory_read` 分页读取完整返回值。图片沿用独立的图片预算。

`attempt_completion` 提交一份待验收的最终回答，验收与直接回复共用同一流程。涉及代码改动、测试、来源或产物时，运行时会按任务要求检查后再结束。

常用命令如下。

```text
/skills list
/skills search bug
/skills show bug_fix
/skills load bug_fix
/skills unload bug_fix
```

Skill 只是低优先级工作流说明；加载 Skill 不执行脚本，也不会自动加载工具或扩大权限。

## 6. 项目工作记忆

项目任务、版本化知识与代码结构索引统一保存在应用目录。用户项目不会创建 `agent_docs/` 或 `.genesis/`。

```text
/project
/project rebuild
/memory list
/memory search 关键词
/memory read 引用
/memory diagnostic
/memory export 新文件.md
```

知识修改使用 `/memory write JSON路径`，字段包括 title、body、kind、sources，修改已有条目还需要 ref、expected_revision。`/memory delete 引用 版本` 先显示预览，追加 `--confirm` 才删除。`/memory rebuild` 重建可派生索引，保留原文。`/memory backup 新文件.sqlite3` 备份数据库；完整备份还需复制 assets 与需要保留的日志。

默认上下文窗口为 400K，输入预算在预留输出和安全余量后为 394880 tokens。模型平时携带近期历史与项目目录，较早原文按需查阅；`/budget` 和 `/memory diagnostic` 展示实际组装信息。详见[记忆系统架构](记忆系统架构.md)。

## 7. 代码与文件任务

代码修改采用行号读取、原文件 SHA-256 和 unified diff。补丁应用前若文件已变化会拒绝覆盖。`run_commands` 自动识别常见 Python、Node 和 Rust 测试入口，也可显式传入命令数组。Git 状态和差异通过 `run_commands` 的只读命令查看。

`/diff` 查看当前运行记录的文件操作、路径和变更前后哈希。

### 文字与图片

先用 `/model` 选择标记为“支持图片”的模型。已接入 Qwen 按量端点的 `qwen3-vl-plus`、`qwen3-vl-flash`、`qwen3.8-max`、`qwen3.8-flash`、`qwen3.7-plus`，以及 Token Plan 端点的 `qwen3.8-max`、`qwen3.8-flash`、`qwen3.7-plus`。其他模型或自定义端点的图片能力未确认时会明确拒绝图片请求，文字对话仍可使用。不会自动切换提供商、端点或模型。

```text
/attach "E:\PROJECT\GenesisAI\src\genesisai\app\assets\pet\spritesheet.webp"
请描述这张图片里的角色和排列方式
```

可以重复 `/attach` 添加多图；`/attachments` 查看待发图片，`/attachments clear` 移除待发附件，`/send` 仅发送图片。附件在成功登记本轮消息后移出草稿，登记前失败会保留。路径使用现有授权范围；工作区外图片需符合当前文件访问权限。选择附件时会检查和冻结像素，排队期间原文件变化不会更换已选择的图片。切换会话或退出会丢弃未发送的内存附件，原文件保留。

单次执行支持重复 `--image`，纯图片请求可省略 `--prompt`：

```powershell
genesis --workspace E:\PROJECT\GenesisAI --image E:\PROJECT\GenesisAI\src\genesisai\app\assets\pet\spritesheet.webp --prompt "描述图中的角色"
```

本期支持静态 PNG、JPEG、WebP，不接入视频、音频、动画图片、剪贴板截图或远程图片 URL 下载。默认每次请求最多 4 张图片，原图单张不超过 10 MiB、解码不超过 3200 万像素；保持比例缩放至最长边 1536，规范化 PNG 后单张同样不超过 10 MiB，请求图片合计不超过 12 MiB。图片会消耗上下文，`/budget` 展示图片数量、估算 Token 与字节。可在模型 `context` 配置中调整这些应用限制；供应商实际限制仍以其接口为准。

模型可通过 `read_image(path=...)` 查看授权图片，用 `read_image(image_ref=...)` 重读历史图片。MCP 的 text/image 内容也走同一链路；不支持的内容类型会明确报错。图片快照位于会话状态根目录的 `images/<session_id>/` 下，对话与日志保存引用或载荷摘要，不重复内嵌 Base64。历史图片可以从工作上下文卸载，原对话及快照保留，后续可按引用重新读取。快照损坏或缺失时提示重新附图，不猜测视觉内容。

图片能力依据：[千问视觉模型说明](https://platform.qianwenai.com/docs/developer-guides/getting-started/text-generation-models)、[Token Plan 视觉支持](https://platform.qianwenai.com/docs/token-plan/best-practices/add-vision-skill)。

## 8. 网络研究

网络研究遵守 `query → candidate → fetch → Evidence → answer`。搜索结果摘要只是候选，只有抓取并登记过的正文才能成为 `src_` 引用。相同 Session 中的后续追问会优先复用上一轮 Evidence，避免重新搜索和反复授权。

## 9. 办公文件

安装 `genesisai[office]` 后可按需启用：

| 格式 | V1 能力 |
| --- | --- |
| DOCX | 段落、表格、页眉页脚读取；基础创建；文字替换式有限编辑 |
| XLSX | 工作表、值、公式和合并区域读取；基础创建；指定单元格修改 |
| PPTX | 幻灯片文字、备注和对象数量读取；标题与项目符号基础创建 |
| PDF | 页数、元数据和可提取文字读取；基础文本 PDF 创建 |

所有修改结果写为新产物，输入原件不覆盖。XLSX 公式只写入、不重新计算；扫描 PDF 没有 OCR；PPTX/PDF 不承诺任意原稿的高保真编辑。

## 10. 终端操作、恢复与诊断

交互终端使用多行输入区。Enter 发送，Alt+Enter 或 Ctrl+J 换行，方向键编辑和浏览输入历史。粘贴多行内容后按 Enter 提交。输入 `/` 即显示命令候选，支持命令名和中文说明搜索。↑↓ 选择，Enter 执行，Tab 补全，Esc 收起候选。`/help` 打开同一命令选择器，Esc 返回任务输入。

普通启动显示当前工作区和最近五段有内容的对话。输入第一条消息才新建会话；空输入框按 ↑ 选择最近对话，`/sessions` 查看全部工作区。选中会话或使用 `--session` 后直接显示最近三轮问答，`/history` 显示全文。打开历史无需模型凭据；发送任务时按需配置模型，会话上下文和相关工具结果会随请求发送给所选提供商。首次明确执行开发任务时才提示初始化项目记忆。用 `/new` 回到首页，或用 `/workspace 路径` 切换工作区。完整目录与运行信息在 `/status` 中查看。执行过程显示文件操作与命令结果，`/details` 展开或收起工具输出，`/logs` 提供完整日志路径。运行时 Ctrl+C 停止任务，空闲输入时 Ctrl+C 清空草稿，再按一次退出。

项目记录初始化和待确认操作使用方向键选择。Esc 离开操作确认菜单后，可输入 `/approve`、`/reject`、`/cancel` 或 `/exit`。非交互输入使用普通文本和序号菜单。

交互终端中，任务运行时仍可编辑输入。此时按 Enter 提交的普通消息按顺序排队，轮到它时才进入模型上下文。当前回答保存为成功后，队首自动开始。等待工具授权时，队列也等待。取消、失败、部分完成或到达预算上限后，使用 `/queue resume` 继续。用 `/status` 查看当前阶段，`/queue` 查看队列，`/queue clear` 移除所有尚未开始的消息。切换会话前需要处理队列。退出会丢弃内存中的队列，已执行的任务仍保存在原会话。

输入 `/cancel` 可中止模型等待或受控命令及其子进程。已经启动的命令可能留下文件修改，取消结果会保留这条信息。其他已开始的同步工具会在返回后处理取消。命令输出较快时，终端合并显示并提示省略。使用 `/logs` 查看完整的脱敏输出。运行中 Ctrl+C 先清空草稿，空输入框按 Ctrl+C 请求取消。

如果队首消息在新一轮保存前启动失败，该消息会回到队首。处理错误后可用 `/queue resume` 重试。已经登记的新一轮执行失败时，继续队列会从下一项开始。

- `/compact` 压缩历史工作上下文并保存会话检查点；原始对话和日志保留。待确认工具须先处理，短上下文可能无需压缩。自动压缩按单次请求容量触发，累计 Token 仅统计用量，不再按 75% 强制结束任务。`/budget` 分别显示两者；容量与摘要策略通过模型配置的 `context` 设置，详见 [上下文预算与压缩续跑](问题及解决清单/004-上下文预算与压缩续跑.md)；
- 输入 `/` 选择 `/sessions` 恢复历史聊天，也可直接输入 `/sessions`。选择后使用该会话的原工作区继续。
- `genesis --seconds 1800 --request-timeout 120 --max-rounds 60 --max-tools 180` 设置任务总时限、单次模型请求超时、模型交互轮次和工具调用硬上限。默认分别为 1800 秒、60 秒、60 轮和 180 次，`/budget` 显示实际配置。单轮内部重试另受超时与重试次数限制；摘要调用单独记账并受剩余总时限约束。每 20 轮记录进度检查点；切换能力或恢复同一运行不会重置消耗和硬上限，用户新输入会建立新 Run。
- `/resume` 恢复可安全继续的运行，`started/unknown` 副作用不会自动重放；

出现失败时使用 `/status` 查看状态、`/trace` 查看执行摘要、`/logs` 获取完整日志路径。待确认状态使用 `/approve` 或 `/reject`。

项目文件和应用任务状态更新后可以继续同一会话。应用保留历史哈希，将已变化或删除的文件快照标为失效，并提示模型按需重新读取；旧来源不能作为当前文件内容的证据。批准执行的修改和测试与直接执行采用相同的状态更新。普通问答和创作正文随模型生成逐段显示。工具调用在参数接收完整后执行，需要核实来源或验收的回答在检查后展示。流式正文输出前停止加载动画；若最终状态与模型正文不一致，界面额外显示运行时的判定原因。

## 编码工具

- `search_codebase` 的 `content` 模式返回路径、从 1 开始的行列、匹配片段和前后文。用 `context_lines` 调整上下文宽度。先按 `next_offset` 读取本批命中，再以 `next_file_offset` 作为 `file_offset` 并把 `offset` 归零，继续扫描下一批文件。Office 和 PDF 的行号对应提取后的文字。
- `context_lines` 最大 40；`output_mode=files/count` 可返回命中文件或匹配行数，`max_output_chars` 限制输出量。`mode=index` 支持 `next_cursor` 分页，文件集合或元数据变化后旧游标失效，需重新开始。索引明确标记单文件截断和解析失败；Python 使用现有项目索引的 AST 解析，JS/TS 当前为正则覆盖，不代表完整语义分析。
- `read_files.files` 可为各文件指定独立行范围或字符偏移，不能与 `path/paths` 混用。默认整次正文上限为 24000 字符，使用 `remaining_requests` 作为下一次的 `files` 继续读取。普通源码字符分页可读取 20 万字符以后的内容；Office/PDF 仍受文档提取上限约束。
- `discover_tools` 默认返回并加载 6 个候选，最多 12 个；`activate=false` 只查看候选。需要使用时可按精确工具名再次发现。工具发现、任务路由和 Skill 均不扩大权限；本地开发可按需使用网页工具，用户禁网或只读要求仍约束实际执行。
- 后台命令返回 `job_id` 后，用 `read_job(job_id=..., wait_seconds=30, output=true)` 有界等待并分页读取输出。测试作业完成后会返回摘要，旧测试不能验证启动后修改的文件；恢复时若作业所有者不可用，不自动重放命令。
- `editor` 的 `replace` 接受 `path`、`old_text`、`new_text`，旧文字须恰好匹配一次。`patch` 支持单个文件，也支持 `patches` 数组。批量操作先逐个预检，确认时展示每个文件的 diff。执行过程中发生冲突时，结果会列出已修改、失败和待处理的文件，已写入的文件保留备份。
- `run_commands` 设置 `background=true` 后返回会话内的 `job_id`。`read_job` 不传编号时列出最近作业，传入编号和 `output=true` 可按字符偏移读输出。`stop_job` 终止该作业的进程树。每个会话同时最多四个作业，每个作业最长 600 秒，合并保留最多 256000 个字符的输出。退出应用、关闭会话或从自动权限降级时，宿主停止它所持有的作业。重新打开会话可以查看已保存的状态和输出。宿主异常断开时显示 `owner_unavailable`。
- 模型调用 `ask_user` 时，会话进入 `awaiting_input`。直接输入文字、选项编号或 `/answer 文字` 即可继续同一任务。可保存退出，在原会话继续作答。`/cancel` 结束任务。

### 项目语言服务和 MCP 资源

启动 MCP 子进程时，GenesisAI 会过滤父进程中名称含 `KEY`、`TOKEN`、`SECRET`、`PASSWORD` 或 `CREDENTIAL` 的环境变量。若某个服务需要凭据，请在应用管理的项目 `mcp.json` 中为该服务单独设置 `env`。服务配置里的 `read_only` 接受 JSON 布尔值 `true` 或 `false`。

在应用管理的项目目录 `%USERPROFILE%\.genesisai\projects\<project_id>\` 放置扩展配置。用户项目只需保留自己的源码和配置。用户权限模式会在启动外部服务前展示命令。

`lsp.json` 按文件后缀选择语言服务。例如，安装 `python-lsp-server`（可选依赖 `genesisai[lsp]`）后，可使用以下配置。`pylsp` 须能从应用的 PATH 启动，也可替换为绝对路径。

~~~json
{"servers": {".py": {"language": "python", "command": ["pylsp"]}}}
~~~

重新打开会话后，`lsp_query` 支持 `definition` 和 `references`。输入和输出的行列均从 1 开始，列按 UTF-16 代码单元计数。每次查询启动一个受时限管理的服务实例，只返回当前工作区内的位置。

`mcp.json` 中的服务声明 `resources` 能力后，调用 `connect_mcp` 即可发现 `list_mcp_resources`、`list_mcp_resource_templates` 和 `read_mcp_resource`。列表返回的 `nextCursor` 可作为下一次调用的 `cursor`。读取时向对应服务器传入完整 URI，返回文字或经应用图片校验后的图片引用。外部工具按服务器提供的 JSON Schema 校验嵌套参数、枚举和本地引用。服务器报告 `isError` 时，该调用以失败写入账本。
