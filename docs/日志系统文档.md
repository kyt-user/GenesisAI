# GenesisAI 日志系统文档

## 概述

GenesisAI 日志系统是一个完整的 core 层实现，提供配置管理、存储查询、日志分析等功能。

## 架构

```
core/state/logger.py
├── LogLevel          # 日志级别枚举
├── LogCategory       # 日志分类枚举
├── LogRecord         # 日志记录数据结构
├── LogConfig         # 日志配置管理器
├── LogStore          # 日志存储和查询管理器
├── LogAnalyzer       # 日志分析器
└── RunLogger         # Agent 运行日志记录器（整合以上功能）
```

## 核心组件

### 1. LogConfig - 日志配置管理器

```python
from genesisai.core.state.logger import LogConfig, LogLevel

config = LogConfig(
    log_dir=Path("logs"),           # 日志目录
    level=LogLevel.INFO,            # 日志级别
    max_file_size_mb=10,            # 单个日志文件最大大小（MB）
    backup_count=5,                 # 保留的日志文件数量
    enable_console=False,           # 是否启用控制台输出
    console_level=LogLevel.WARNING, # 控制台日志级别
)
```

### 2. LogRecord - 日志记录数据结构

```python
from genesisai.core.state.logger import LogRecord

record = LogRecord(
    timestamp="2026-10-08T18:20:55",
    level="INFO",
    category="model_input",
    round_num=1,
    message="模型输入 - 2 条消息",
    metadata={"message_count": 2, "tool_count": 21}
)

# 转换为字典
data = record.to_dict()

# 从字典创建
record = LogRecord.from_dict(data)
```

### 3. LogStore - 日志存储和查询管理器

```python
from genesisai.core.state.logger import LogStore, LogCategory

store = LogStore(config)

# 添加记录
store.add_record(record)

# 查询记录
tool_records = store.get_tool_executions()           # 获取所有工具执行记录
model_records = store.get_model_interactions()       # 获取所有模型交互记录
round_records = store.get_round_summary(1)           # 获取指定轮次的记录

# 按条件查询
records = store.get_records(
    category=LogCategory.MODEL_INPUT,
    round_num=1,
    level=LogLevel.INFO
)

# 导出为 JSON
store.export_to_json(Path("output.json"))

# 获取统计信息
stats = store.get_statistics()
```

### 4. LogAnalyzer - 日志分析器

```python
from genesisai.core.state.logger import LogAnalyzer

analyzer = LogAnalyzer(store)

# 分析工具性能
tool_perf = analyzer.analyze_tool_performance()
# 返回: {
#   "list_files": {
#     "count": 5,
#     "total_elapsed_ms": 155,
#     "success_count": 5,
#     "fail_count": 0,
#     "avg_elapsed_ms": 31.0
#   }
# }

# 分析模型使用
model_usage = analyzer.analyze_model_usage()
# 返回: {
#   "total_rounds": 10,
#   "total_tokens": 85486,
#   "total_elapsed_ms": 45000,
#   "avg_tokens_per_round": 8548.6,
#   "avg_elapsed_ms_per_round": 4500.0
# }

# 生成分析报告
report = analyzer.generate_report()
```

### 5. RunLogger - Agent 运行日志记录器

```python
from genesisai.core.state.logger import RunLogger

# 初始化（需要 store 和 session_id）
logger = RunLogger(store, session_id="abc123")

# 记录模型输入
logger.log_model_input(round_num=1, messages=messages, tools=tools)

# 记录模型输出
logger.log_model_output(round_num=1, response=response, elapsed_ms=2063)

# 记录工具执行开始
logger.log_tool_execution_start(call_id="call_001", tool_name="list_files", arguments="{}")

# 记录工具执行完成
logger.log_tool_execution_end(call_id="call_001", tool_name="list_files", result=result, elapsed_ms=31)

# 记录轮次摘要
logger.log_round_summary(round_num=1, status="completed", answer="...")

# 导出日志
logger.export_logs()  # 默认路径
logger.export_logs(Path("custom_output.json"))  # 自定义路径

# 获取分析报告
report = logger.get_analysis_report()

# 获取统计信息
stats = logger.get_statistics()
```

## 日志分类

| 分类 | 说明 |
|------|------|
| `model_input` | 模型接收的输入信息 |
| `model_output` | 模型的输出响应 |
| `tool_execution` | 工具执行记录 |
| `run_summary` | 运行摘要 |
| `system` | 系统日志 |

## 日志级别

| 级别 | 说明 |
|------|------|
| `DEBUG` | 调试信息 |
| `INFO` | 一般信息 |
| `WARNING` | 警告信息 |
| `ERROR` | 错误信息 |
| `CRITICAL` | 严重错误 |

## 使用示例

### 示例 1：基本使用

```python
from genesisai.core.state.logger import RunLogger

# 在 Agent 循环中使用
logger = RunLogger(store, session_id="session_123")

# 每轮自动记录
logger.log_model_input(round_num, messages, tools)
logger.log_model_output(round_num, response, elapsed_ms)
logger.log_tool_execution_start(call_id, tool_name, arguments)
logger.log_tool_execution_end(call_id, tool_name, result, elapsed_ms)
logger.log_round_summary(round_num, status, answer)
```

### 示例 2：日志分析

```python
from genesisai.core.state.logger import LogConfig, LogStore, LogAnalyzer

# 创建配置和存储
config = LogConfig(log_dir=Path("logs"))

# ... 添加日志记录 ...

# 分析

```

### 示例 3：日志导出

```python

logger = RunLogger(store, session_id="session_123")

# ... 记录日志 ...

# 导出为 JSON

```

## 集成说明

### 与 Agent 循环集成

`loop.py` 现在 import core 层实现：

```python
from genesisai.core.state.logger import RunLogger

class Runner(RecoveryMixin):
    def __init__(self, model, runtime, *, ...):
        # ... 其他初始化 ...
        self.run_logger = RunLogger(self.store, session_id=self.store.data.get('session_id', 'unknown'))
    
    def _call_model(self, context, tools):
        # 记录模型输入
        self.run_logger.log_model_input(d['rounds'], context, tools)
        
        # ... 调用模型 ...
        
        # 记录模型输出
        self.run_logger.log_model_output(d['rounds'], response, elapsed_ms)
    
    def _execute_pending(self, limits):
        # 记录工具执行开始
        self.run_logger.log_tool_execution_start(call['id'], call['name'], call.get('arguments', '{}'))
        
        # ... 执行工具 ...
        
        # 记录工具执行完成
        self.run_logger.log_tool_execution_end(call['id'], call['name'], result, elapsed_ms)
```

## 注意事项

1. **日志目录**: 日志文件保存在 `<workspace>/.genesis/logs/` 目录
2. **文件命名**: `run_<session_id>_<timestamp>.log`
3. **编码**: 所有日志文件使用 UTF-8 编码
4. **性能**: 日志记录不会影响 Agent 运行性能
5. **存储**: 日志记录存储在内存中，导出时写入磁盘
