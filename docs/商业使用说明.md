## 哪些用法可以直接采用

个人和企业均可在许可证约定范围内运行、研究和修改 GenesisAI。判断收费场景时，要看第三方付费取得什么，以及所购产品或服务的价值来自哪里。

| 使用场景 | 如何判断 |
| --- | --- |
| 公司用 GenesisAI 开发一款收费记账软件 | 可以。客户购买的是记账业务功能，公司可以把 GenesisAI 作为内部开发工具。 |
| 将 GenesisAI 换名、换界面，向客户出售安装包 | 如果付费价值全部或主要来自 GenesisAI 的功能，需要单独商业授权。 |
| 将 GenesisAI 部署为在线 coding agent，通过订阅或 API 按量收费 | 同样按收费价值来源判断。向客户出售 GenesisAI 核心功能的访问权，需要单独商业授权。 |
| 为 GenesisAI 提供独立的付费财务 MCP 服务 | 若客户购买的是开发者自己的数据或财务分析功能，通常可以。若服务包含或转售 GenesisAI，还需按实际交付方式判断。 |
| 收费部署、咨询或技术支持 | Commons Clause 对 “Sell” 的定义明确提到托管、咨询和支持费用。要结合交付内容、收费对象和服务价值来源判断。 |

免费分发项目或修改版时，请随附完整许可证，保留适用的版权、署名和许可声明，并按 Apache License 2.0 第 4 节标明修改过的文件。使用 GenesisAI 编写的独立业务代码可由其权利人决定授权方式；如果交付物里复制或包含 GenesisAI 代码，相应部分继续适用本项目的条款。

可通过[项目仓库](https://github.com/kyt-user/GenesisAI)联系维护者 `kyt-user`。说明准备交付的产品或服务、GenesisAI 在其中提供的功能、部署方式及收费方式即可。公开沟通时只需提供概述，客户资料和密钥请保留在自己的环境中。具体许可范围以双方另行达成的书面授权为准。
