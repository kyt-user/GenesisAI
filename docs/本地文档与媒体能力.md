# 本地文档与媒体能力

Office读取使用 `items`、`coverage` 和 `next`。`next` 可直接作为下一次工具参数，包含源文件SHA256；文件变化后需要重新开始。长操作会返回 `job_id`，使用 `read_job` 收取结果，`stop_job` 取消，不能将作业已提交当作已完成。

- DOCX：按正文/段落/表格/页眉/页脚分页，超长单元使用 `text_offset` 继续。创建可通过 `source` 追加到既有文档副本。
- XLSX：未指定 `sheet` 时分页列工作表；指定 `sheet`/`range` 读取区域，`view` 可单独查公式、样式坐标、合并区域。不会执行Excel公式重算。
- PPTX：分页读取可提取的幻灯片文字与备注，可追加基础幻灯片。不承诺图表和复杂布局语义。
- PDF：`pdf_read` 提取页面已有文字；扫描页明确需要OCR。`pdf_create` 自动换行分页，不静默剪掉长行。

Office产物默认新路径。覆盖需要 `overwrite=true` 与目标当前 `expected_sha256`；写前冲突会拒绝，成功覆盖保存前态备份及修改记录。结构重开验证不等于视觉排版验收。

## 扫描PDF与加密PDF

安装可选本地OCR引擎：

```powershell
python -m pip install "genesisai[ocr]"
```

`pdf_ocr` 使用RapidOCR、ONNX Runtime CPU和PDFium，显式加载安装包内模型，不把文档发送到云端，也不在首次执行时下载模型。引擎或模型缺失会明确报错。按页使用 `offset`/`limit`，按页内字符使用 `text_offset`，沿 `next` 继续。每页默认渲染150dpi，默认最多2000万像素；更大页面降低实际dpi并返回 `effective_dpi`。`GENESISAI_OCR_MAX_PAGE_PIXELS` 可设置本机渲染预算。OCR文字可能有错，手写、多语言、复杂版式必须核对原页。

加密PDF使用用户直接输入的CLI命令：

```text
/pdf-unlock "输入路径.pdf" "新输出文件.pdf"
```

随后在终端隐藏输入密码。不要把密码写进对话或命令行参数。密码不保存为模型参数或会话记录；源文件保持不变，成功后返回新解锁副本。既有输出文件被拒绝。解锁副本不保留原加密，原数字签名不能证明副本未变。

## 本地音视频

安装FFmpeg并将 `ffmpeg` 和 `ffprobe` 所在的绝对目录加入PATH。工具不会自动安装程序，不调用云服务，不打开远程URL或播放列表。支持自包含MP4/MOV、MKV/WebM、AVI、WAV、MP3、FLAC、OGG，由本机解码器实际支持情况决定。

- `media_probe(path)`：返回轨道、编解码器、时长等元数据。
- `video_frames(path, output_prefix, start_seconds, interval_seconds, count)`：按时间点生成最多16张PNG新文件，沿 `next_seconds` 继续。生成帧可用 `read_image` 查看；抽样帧不代表完整视频内容。
- `media_audio(path, output, start_seconds, duration_seconds)`：分段提取16kHz单声道WAV新文件，沿 `next_seconds` 继续。每段最多600秒，长音频分批处理。

音轨提取不会自动转写。所有媒体输出仅写新路径，返回产物引用、哈希和修改记录；缺少引擎、无法解码或来源变化会明确报错。

## 本地语音转写

`audio_transcribe` 是独立的可选能力。安装 `python -m pip install "genesisai[speech]"`，自行准备完整的CTranslate2 Whisper模型目录，并设置 `GENESISAI_WHISPER_MODEL` 为其绝对路径。目录必须包含 `model.bin`、`config.json`、`tokenizer.json`、`vocabulary.txt`。工具只从此目录加载，不自动下载模型；例如 [Systran官方tiny多语模型](https://huggingface.co/Systran/faster-whisper-tiny/tree/main) 约78.2MB，实际识别质量取决于模型和音频。

使用CPU int8推理，默认每次转写60秒，可指定 `start_seconds`、`duration_seconds` 和可选 `language`。较长文件按时间片处理，较长文字按 `segment_offset`/`text_offset` 分页，直接沿 `next` 继续。返回时间戳、语言概率、分段识别指标、源哈希和模型哈希。语音转写不提供说话人分离；分块边界可能拆词，识别结果需要听原音核对。
