## 更新时的共同口径

1. 区分已实现能力、可选依赖和已验证场景；明确默认值属于应用配置还是外部服务规格。
2. 主会话保持单 Agent；并发后台作业、独立 Skill 测试会话不写成多 Agent 编排。
3. 工具数量注明是否包含 YAML 工具、动态内置管理接口、LSP、外挂或 MCP；实际可用清单以运行时为准。
4. 统一使用应用目录 `~/.genesisai/`（可由 `GENESISAI_HOME` 覆盖），保留 ENV 密钥优先、终端密钥回退和当前格式会话恢复。
5. 区分前台等待、作业总时限与任务预算；提交成功不能当作执行成功，未知副作用不自动重放。
6. 文档结构校验、OCR/转写和抽帧均应写明覆盖范围；不将其描述成视觉保真或完整内容理解。
7. 历史诊断、失败报告和待办原文保留；补充当前入口或有证据的核销记录，不把旧结果改写成新测试结果。
